Quick start

One prefix. Plenty to explore.

Madoka is a Discord bot that helps with server safety, moderation, music, and community tools. Its default prefix is >. Server administrators can change it with setprefix !; the exclamation mark is only an example. Slash commands can also be available in Discord's command menu.

Start here

Set up Madoka in your server

A quick, safe checklist to help your community get started.

01

Invite the bot

Use the Invite bot button and choose the Discord server where you have permission to add bots. Review the requested permissions before confirming.

02

Choose a command channel

Make sure Madoka can view the channel and send messages there. For moderation or setup actions, the bot and the person running the command also need the relevant Discord permissions.

03

Try a command

Try >ping or browse the categories below. Use the server's active prefix; setprefix ! shows how an administrator could switch to !.

Permissions, roles, and server safety

Discord controls what Madoka can do. Give it only the permissions its enabled features need, and keep its role below roles it should not manage. Commands such as ban, kick, channel locking, and role management depend on both Discord permissions and the bot role's position.

Use destructive actions carefully, review the target before confirming, and avoid sharing private tokens or account credentials. If a command is denied, check the bot's channel access, role position, and the permissions of the person running it.

Prefix and slash commands

The default prefix shown for Madoka is >. A server administrator can change it with setprefix !; ! is just an example, and your server may use a different prefix afterward. Put the active prefix directly before a prefix command, such as >help with the default.

Slash commands are selected from Discord's built-in command menu and do not need a message prefix. Availability can depend on the command and server configuration.

Music and voice troubleshooting

For music commands, join the voice channel first and check that Madoka can view and connect to it. If playback or a command does not work, confirm the bot is online, the channel permissions allow it, and the command is available to your server.

Some features require additional Discord permissions or server setup. Check the relevant category guide and ask in the support server if the issue continues.

Where to get help

Use the command search and category browser below to look up documented commands. For a bug report, include what you tried, the server/channel context, and any error message—but do not post passwords, bot tokens, or other secrets.

For help from the team, visit Madoka Developers or join the Virtus X Devs community using the links on this site.
