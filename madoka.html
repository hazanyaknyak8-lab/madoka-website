Quick start guide

Follow these steps to get Madoka working in your server.

1. Invite Madoka

Use the Discord invite, choose your server, and review the requested permissions.

2. Check where it can respond

Make sure Madoka can view the channel, read messages, and send messages. Some features need additional permissions or setup.

3. Run a command

Type the prefix > followed by a command, for example >ping. Commands shown with / are Discord slash commands.

Command availability and required permissions can vary by server setup. If a command does not respond, check the bot's channel permissions and the command spelling.
